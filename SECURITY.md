# Security

Use [private vulnerability reporting](https://github.com/dimabalony/memory-evaluation/security/advisories/new)
for suspected vulnerabilities. Do not post credentials, transcripts, personal
fixtures, or exploit details in public issues. The current 0.1 release line is
supported for security fixes.

Evaluation adapters may execute supplied model functions or access storage.
Use dedicated local disposable databases and explicitly bounded provider
accounts. Installing this package does not authorize provider calls.
